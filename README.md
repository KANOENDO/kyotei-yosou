# kyotei-yosou

ボートレース（競艇）の予想と、その検証を毎日自動で回すプロジェクトです。
公式データから選手・モーター・水面の情報を集めて予想を立て、**仮想購入（ペーパートレード）** で「その予想で買っていたら回収率はどうだったか」を記録・検証します。

> **実際の舟券購入は一切行いません。** 購入額・払戻額・収支はすべて仮想の値です。

## 仕組み

予想から検証までを、Claude のスケジュール実行で1日を通して自動化しています。

| ルーティン | 実行タイミング | 役割 |
| --- | --- | --- |
| 朝の回 | 毎日 8:00（JST） | 前日の結果検証、当日全レースの予想（本命・対抗・自信度）、オッズを使わない仮買い目の作成、締切スケジュールの保存 |
| 確定の回 | 30分ごと | 締切の約40分前〜4分前のレースについて、展示・進入・天候などの直前情報と最新オッズで買い目を修正・確定 |

対象場は大村・徳山・下関です。1日1回、検証結果と改善案を Discord に通知します（改善案は提案のみで、ルールやコードは自動では変更しません）。

## 予想モデル（v2）

1着・2着・3着それぞれの「選ばれやすさ」を推定する、段階別の Plackett–Luce（条件付きロジット）モデルです。

- 特徴量：コース別成績（1着率・2連率・3連率）、場ごとのコース成績、直近10走の着順とST、全国勝率、モーター、展示タイム、1コース×風速・波高
- 学習・検証データ：公式の競走成績（Kファイル）とファン手帳
- モデル自体はオッズを使わず、買い目を選ぶ段階で市場オッズと組み合わせます

## 買い目のルール

- レースは絞らず、対象場の全レースを 3連単・1レース 1,000円（100円単位）で仮想購入
- 取りガミ回避：買い目1点ごとに「オッズ × 金額 ≧ 1,500円」を満たすものだけを買う。満たせない分は購入額を減らす（0円もあり）
- オッズは取りガミ判定と買い目の選択にだけ使い、予想（本命・対抗）の修正には使わない（検証を歪めないため）

## ディレクトリ構成

```
tools/     データ取得・モデル・買い目作成・評価のスクリプト
prompts/   朝の回・確定の回のプロンプト
data/      公式データ（Kファイル、ファン手帳）と加工済みデータ
reports/   日次レポート（kyotei_YYYYMMDD.md）
sim/       初期のシミュレーション（モデルv1）
kyotei_log.csv  全レースの予想・買い目・結果・払戻の記録
```

## 主なコマンド

```bash
python3 tools/kfiles.py fetch YYYYMMDD YYYYMMDD   # 期間の競走成績を取得・展開
python3 tools/kfiles.py build                     # 成績データから race_history.csv を作成
python3 tools/kfiles.py recent 登番 [登番...]      # 選手の直近10走を表示
python3 tools/kfiles.py payout YYYYMMDD 場コード   # その日の払戻金一覧を表示
python3 tools/backtest_v2.py                      # モデルv2のバックテスト
```

ファン手帳の展開に `lhafile` が必要です（`pip install lhafile`）。Discord 通知を使う場合は環境変数 `DISCORD_WEBHOOK_URL` を設定してください。

## 注意

競艇の控除率は約25%で、長期的な期待回収率は平均75%前後です。このリポジトリは予想手法の検証を目的としたもので、実際の購入を勧めるものではありません。
